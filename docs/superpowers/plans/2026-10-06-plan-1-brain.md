# Snoop Plan 1 — The Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sandboxed, read-only "brain" that answers questions about the Agent-C repo, runnable on any roster member's Mac from a local clone with `./snoop setup` (once) and a brain process the Conductor (Plan 2) starts.

**Architecture:** Host-side Python (`yosnoop/`) prepares knowledge in `/Users/Shared/snoop` (clone, PR/CI status file, repo map, registry bundle on Brett's Mac) and launches the brain as macOS user `snoop` via a narrow sudoers rule. The brain is a long-lived process speaking JSON lines on stdin/stdout; it holds one Claude Agent SDK session per meeting, with read-only tools only. The host's home is `700`, so the brain physically cannot read the host's files. Every answer passes a secret-scanning gate before it leaves the host side.

**Tech Stack:** Python 3.12 (`uv`), `claude-agent-sdk` (P3: 0.2.163), `mcp` (tool listing), Serena (`serena-agent`, pinned), repomix (`npx repomix@<pinned>`), Agent-C `registry-mcp` (Node), macOS `sysadminctl`/`dseditgroup`/`visudo`, `gh`.

**Spec:** `docs/superpowers/specs/2026-10-05-yo-snoop-design.md` — D1, D12, D15, D16, D20–D23, D25, D33–D35; §3.2, §5. Plan 0 findings: `docs/superpowers/findings/2026-10-plan-0-findings.md` (P3 is required reading).

**Depends on Plan 0:** only P3 (done). Can be built before the Meet probes finish.

## Global Constraints

- Phase 1 scope (D33): no pre-loading, no pacing. One SDK session per meeting is still used (follow-ups work).
- No code names a person; hosts come from `config/team.json` (D31) and `~/.config/snoop/host.json`.
- The brain process runs as `snoop` in production; it holds **no stored credential**. The API key arrives on stdin (D35). `--dev` runs as the host on the host's own Claude login, sandbox off, and prints a warning on every start.
- SDK options are always: `setting_sources=[]`, `strict_mcp_config=True`, `permission_mode="dontAsk"`, explicit `allowed_tools`, `max_turns=15` (P3). Never `bypassPermissions`.
- Host-side secrets live in `~/.config/snoop/secrets/` (mode 700) — readable by the host only, because the host's home is `700`.
- No secret is printed, committed, logged, or put on a command line. Tests build key-shaped strings by concatenation so the repo never contains one.
- Paths: shared root `/Users/Shared/snoop` (`SHARED`). Tests use a temp dir via the `SNOOP_SHARED` env var.
- Disk: stop if under 25 GiB free.

## Review Focus

1. **Brain reads the host's files** — if setup's home lockdown silently fails, the wall is gone. Expected: `snoop doctor` fails loudly. Pinned in Task 9, Step 3.
2. **API key leaks** — via a file, argv, logs or an answer. Expected: none; the gate blocks a key-shaped answer. Pinned in Task 4 and Task 9, Step 4.
3. **Registry write through the brain** — expected refused, and the real `~/.agent-c` unchanged by hash. Pinned in Task 9, Step 5.
4. **Serena exposes an editing tool after an upgrade** — expected: brain refuses to start. Pinned in Task 6.
5. **Stale knowledge presented as current** — expected: every answer's metadata carries the clone age; Plan 2 speaks it when > 30 min. Pinned in Task 7, Step 1.

# yosnoop/hostcfg.py
import json, os
from pathlib import Path
from yosnoop.roster import Member, Roster

def host_json_path() -> Path:
    return Path(os.environ.get("SNOOP_HOST_JSON", Path(os.environ["HOME"]) / ".config" / "snoop" / "host.json"))

def load_host(roster: Roster) -> Member:
    p = host_json_path()
    if not p.exists():
        raise SystemExit(f"no host config at {p}; run ./snoop setup")
    email = json.loads(p.read_text())["email"]
    m = roster.by_email(email)
    if m is None or not m.may_host:
        raise SystemExit(f"{email} is not a roster member who may host (config/team.json)")
    return m

# yosnoop/setup_mac.py
"""One-time privileged setup. Generates one bash script, shows it, runs it under sudo once."""
import getpass, json, os, subprocess, tempfile
from pathlib import Path
from yosnoop import paths
from yosnoop.roster import load
from yosnoop.cli import ROSTER


def setup_script(owner: str, owner_home: str, shared: str) -> str:
    return f"""#!/bin/bash
set -euo pipefail
# 1. snoop user: standard, hidden, no login shell, random throwaway password
if ! id snoop >/dev/null 2>&1; then
  sysadminctl -addUser snoop -fullName "Snoop Brain" -shell /usr/bin/false -password "$(openssl rand -base64 24)" -home /Users/snoop
  createhomedir -c -u snoop >/dev/null
fi
dscl . create /Users/snoop IsHidden 1
# 2. group that may read the shared knowledge
dseditgroup -o read snoopread >/dev/null 2>&1 || dseditgroup -o create snoopread
dseditgroup -o edit -a snoop -t user snoopread
# 3. shared dir: owner writes, snoop reads
mkdir -p {shared}/knowledge {shared}/runtime {shared}/bin
chown -R {owner}:snoopread {shared}
chmod 750 {shared}
chmod -R g+rX,o-rwx {shared}
# 4. the wall: owner's home closed to every other local user
chmod 700 {owner_home}
# 5. owner may start the brain as snoop, nothing else
TMP=$(mktemp)
echo '{owner} ALL=(snoop) NOPASSWD: {shared}/bin/brain' > "$TMP"
visudo -cf "$TMP"
install -m 0440 -o root -g wheel "$TMP" /etc/sudoers.d/snoop
rm -f "$TMP"
echo "snoop setup: done"
"""


def run_setup(argv: list[str]) -> int:
    roster = load(ROSTER)
    email = input("Your saasless.ai email (must be in config/team.json): ").strip().lower()
    m = roster.by_email(email)
    if m is None or not m.may_host:
        print(f"{email} is not a roster member who may host"); return 1
    host_json = Path(os.environ["HOME"]) / ".config" / "snoop" / "host.json"
    host_json.parent.mkdir(parents=True, exist_ok=True)
    host_json.write_text(json.dumps({"email": m.email}))
    paths.secrets_dir()
    script = setup_script(getpass.getuser(), os.environ["HOME"], str(paths.shared()))
    print(script)
    if input("Run this once with sudo? Type 'yes': ").strip() != "yes":
        print("not run"); return 1
    with tempfile.NamedTemporaryFile("w", suffix=".sh", delete=False) as f:
        f.write(script)
    rc = subprocess.run(["sudo", "bash", f.name]).returncode
    os.unlink(f.name)
    if rc != 0:
        print(f"setup failed rc={rc}"); return rc
    from yosnoop.doctor import run_doctor
    return run_doctor([])
```

# yosnoop/runtime_sync.py
import shutil, subprocess
from pathlib import Path

AGENT_C = Path.home() / "Code" / "Saasless" / "Agent-C"


def brain_wrapper(runtime: Path) -> str:
    return f"#!/bin/sh\nexec {runtime}/.venv/bin/python -m yosnoop.brain_main \"$@\"\n"


def sync_runtime(repo_root: Path, runtime: Path, runner=subprocess.run) -> None:
    runtime.mkdir(parents=True, exist_ok=True)
    py_dir = runtime / "python"
    runner(["uv", "python", "install", "3.12", "--install-dir", str(py_dir)], check=True)
    runner(["uv", "venv", "--python", str(py_dir), "--allow-existing", str(runtime / ".venv")], check=True)
    runner(["uv", "pip", "install", "--python", str(runtime / ".venv" / "bin" / "python"), str(repo_root)], check=True)
    reg = AGENT_C / "registry-mcp"
    if (reg / "out").exists():
        dest = runtime / "registry-mcp"
        if dest.exists():
            shutil.rmtree(dest)
        shutil.copytree(reg / "out", dest / "out")
        shutil.copytree(reg / "node_modules", dest / "node_modules", symlinks=True)
        shutil.copy2(reg / "package.json", dest / "package.json")
```

`pyproject.toml` gains a `[build-system]` (hatchling) and `[tool.hatch.build.targets.wheel] packages = ["yosnoop"]` so `uv pip install <repo>` installs the `yosnoop` package.

# yosnoop/gate.py
import re
from dataclasses import dataclass

BLOCKED = "Snoop here, can't share that one."
PATTERNS = {
    "anthropic-key": re.compile(r"sk-ant-[A-Za-z0-9_-]{20,}"),
    "github-token": re.compile(r"\b(ghp|gho|ghu|ghs|ghr)_[A-Za-z0-9]{30,}\b"),
    "github-pat": re.compile(r"github_pat_[A-Za-z0-9_]{40,}"),
    "aws-access-key": re.compile(r"\bAKIA[0-9A-Z]{16}\b"),
    "private-key": re.compile(r"-----BEGIN [A-Z ]*PRIVATE KEY-----"),
    "google-service-account": re.compile(r'"type"\s*:\s*"service_account"'),
    "generic-bearer": re.compile(r"\bBearer\s+[A-Za-z0-9._-]{30,}"),
}


@dataclass(frozen=True)
class GateResult:
    allowed: bool
    text: str
    reason: str | None


def scan(text: str) -> list[str]:
    return [name for name, rx in PATTERNS.items() if rx.search(text)]


def gate(answer: str) -> GateResult:
    try:
        hits = scan(answer)
    except Exception:
        return GateResult(False, BLOCKED, "scanner-error")
    if hits:
        return GateResult(False, BLOCKED, "secret:" + ",".join(hits))
    return GateResult(True, answer, None)
```

# yosnoop/refresher.py
import json, subprocess, time
from dataclasses import dataclass, field
from pathlib import Path
from yosnoop.gate import scan

REPOMIX = "repomix@1"  # pin the exact version in Step 4 and ledger it
INCLUDE = "docs/**/*.md,ARCHITECTURE.md,CLAUDE.md,scripts/**/*.js,registry-mcp/src/**/*.ts,agents/**/SKILL.md"


def run_gh(args: list[str]) -> str:
    return subprocess.run(["gh", *args], capture_output=True, text=True, check=True).stdout


def run_repomix(clone: Path, out: Path) -> None:
    subprocess.run(["npx", "-y", REPOMIX, "--compress", "--style", "xml", "--include", INCLUDE,
                    "--output", str(out), str(clone)], check=True, capture_output=True)


@dataclass
class RefreshReport:
    ok: bool
    clone_age_s: float
    map_blocked: bool = False
    errors: list[str] = field(default_factory=list)


class Refresher:
    def __init__(self, origin: str, knowledge: Path, gh=run_gh, repomix=run_repomix, now=time.time):
        self.origin, self.k, self.gh, self.repomix, self.now = origin, Path(knowledge), gh, repomix, now

    def refresh(self) -> RefreshReport:
        self.k.mkdir(parents=True, exist_ok=True)
        clone, errors = self.k / "agent-c", []
        try:
            if (clone / ".git").exists():
                subprocess.run(["git", "-C", str(clone), "fetch", "-q", "--prune", "origin",
                                "+refs/heads/*:refs/remotes/origin/*"], check=True)
                subprocess.run(["git", "-C", str(clone), "reset", "-q", "--hard", "origin/main"], check=True)
            else:
                subprocess.run(["git", "clone", "-q", self.origin, str(clone)], check=True)
            (self.k / "refreshed-at").write_text(str(self.now()))
        except subprocess.CalledProcessError as e:
            errors.append(f"git: {e}")
        try:
            status = {"pull_requests": json.loads(self.gh(["pr", "list", "--state", "all", "--limit", "30",
                                                           "--json", "number,title,state,author,mergedAt,reviewDecision,headRefName"])),
                      "runs": json.loads(self.gh(["run", "list", "--limit", "30",
                                                  "--json", "headBranch,conclusion,status,createdAt,workflowName"]))}
            (self.k / "pr-ci-status.json").write_text(json.dumps(status, indent=1))
        except Exception as e:
            errors.append(f"gh: {type(e).__name__}")
        blocked, map_path = False, self.k / "repo-map.xml"
        try:
            self.repomix(clone, map_path)
            if scan(map_path.read_text()):
                map_path.unlink(); blocked = True
        except Exception as e:
            errors.append(f"repomix: {type(e).__name__}")
        age = self.now() - float((self.k / "refreshed-at").read_text()) if (self.k / "refreshed-at").exists() else float("inf")
        return RefreshReport(ok=not errors, clone_age_s=age, map_blocked=blocked, errors=errors)

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

KEEP = frozenset({
    "read_file", "list_dir", "find_file", "search_for_pattern", "get_symbols_overview", "find_symbol",
    "find_referencing_symbols", "find_implementations", "find_declaration", "get_diagnostics_for_file",
    "get_diagnostics_for_symbol", "read_memory", "list_memories"})
REMOVED = frozenset({
    "create_text_file", "replace_content", "replace_in_files", "delete_lines", "replace_lines", "insert_at_line",
    "replace_symbol_body", "insert_after_symbol", "insert_before_symbol", "rename_symbol",
    "write_memory", "delete_memory", "rename_memory", "edit_memory", "onboarding",
    "execute_shell_command", "serena_repl", "open_dashboard", "activate_project", "remove_project",
    "query_project", "list_queryable_projects", "restart_language_server",
    "initial_instructions", "serena_info", "get_current_config"})
ALL_KNOWN = KEEP | REMOVED


def project_yml(name: str) -> str:
    excluded = "\n".join(f"  - {t}" for t in sorted(ALL_KNOWN - KEEP))
    return f"project_name: {name}\nread_only: true\nexcluded_tools:\n{excluded}\n"


def assert_tools(exposed: set[str]) -> None:
    extra = sorted(exposed - KEEP)
    if extra:
        raise RuntimeError(f"Serena exposes tools outside the keep list: {extra}")


async def list_tools(command: list[str]) -> set[str]:
    params = StdioServerParameters(command=command[0], args=command[1:])
    async with stdio_client(params) as (r, w):
        async with ClientSession(r, w) as s:
            await s.initialize()
            return {t.name for t in (await s.list_tools()).tools}

DISALLOWED = ["Write", "Edit", "NotebookEdit", "WebFetch", "WebSearch", "Task"]
REGISTRY_READ_TOOLS = ["registry_list", "registry_get", "stage_get", "stage_diagnose", "backlog_list",
                       "backlog_get", "history_events", "history_metrics", "server_info"]
SYSTEM = """You are Snoop, answering a Saasless team meeting's questions about the Agent-C repo.
Answer only from the files and tools you have. If you cannot find it, say "not in my notes".
Lead with the answer. Plain sentences, no markdown, no code blocks; say identifiers exactly.
Return your answer as short self-contained points, most important first.
Read pr-ci-status.json for pull requests and CI; never claim CI passed unless a run says so."""


def build_options(knowledge: Path, registry_cmd, serena_cmd, model: str, persona: str = "") -> ClaudeAgentOptions:
    allowed, servers = list(BASE_TOOLS), {}
    if registry_cmd:
        servers["registry"] = {"type": "stdio", "command": registry_cmd[0], "args": registry_cmd[1:],

        allowed += [f"mcp__serena__{t}" for t in sorted(KEEP)]
    return ClaudeAgentOptions(
        allowed_tools=allowed, disallowed_tools=DISALLOWED, mcp_servers=servers, strict_mcp_config=True,

# yosnoop/brain_main.py
"""The brain. Runs as `snoop` (production) or the host (--dev). JSON lines on stdin/stdout."""
import asyncio, json, os, sys, time
from pathlib import Path

def out(obj): sys.stdout.write(json.dumps(obj) + "\n"); sys.stdout.flush()

def selftest(paths):
    readable, unreadable = [], []
    for p in paths:
        try:
            open(p, "rb").read(1); readable.append(p)
        except OSError:
            unreadable.append(p)
    out({"readable": readable, "unreadable": unreadable})

def clone_age(k: Path) -> float:
    f = k / "refreshed-at"
    return time.time() - float(f.read_text()) if f.exists() else float("inf")

async def serve():
    from claude_agent_sdk import ClaudeSDKClient, ResultMessage
    from yosnoop.brain_opts import build_options
    from yosnoop import paths
    k = paths.knowledge_dir()
    cfg = json.loads((k / "brain-config.json").read_text()) if (k / "brain-config.json").exists() else {}
    credential, client = None, None
    loop = asyncio.get_running_loop()
    while True:
        line = await loop.run_in_executor(None, sys.stdin.readline)
        if not line:
            break
        msg = json.loads(line)
        t = msg.get("type")
        if t == "key":
            os.environ["ANTHROPIC_API_KEY"] = msg["value"]; credential = "key"; continue
        if t == "dev":
            credential = "dev"; continue
        if t == "end_meeting":
            if client: await client.__aexit__(None, None, None); client = None
            continue
        if t != "ask":
            continue
        if credential is None:
            out({"type": "error", "id": msg["id"], "reason": "no-credential"}); continue
        try:
            if client is None:
                client = ClaudeSDKClient(options=build_options(k, cfg.get("registry_cmd"), cfg.get("serena_cmd"),
                                                               cfg.get("model", "claude-sonnet-5-5"), cfg.get("persona", "")))
                await client.__aenter__()
            await client.query(f"[{msg['asker']} asks, room={msg['room']}] {msg['question']}")
            text = ""
            async def collect():
                nonlocal text
                async for m in client.receive_response():
                    if isinstance(m, ResultMessage):
                        text = m.result or ""
            await asyncio.wait_for(collect(), timeout=90)
            out({"type": "answer", "id": msg["id"], "text": text, "clone_age_s": clone_age(k)})
        except asyncio.TimeoutError:
            out({"type": "error", "id": msg["id"], "reason": "timeout"})
        except Exception as e:
            out({"type": "error", "id": msg["id"], "reason": type(e).__name__})

def main():
    if len(sys.argv) > 1 and sys.argv[1] == "--selftest":
        selftest(sys.argv[2:]); return
    asyncio.run(serve())

if __name__ == "__main__":
    main()
```

# yosnoop/bundle.py
import json, shutil
from pathlib import Path

TOP_FILES = ("registry.json", "events.ndjson", "runs.json", "recent.json")
PROJECT_GLOBS = ("docs/**/state.json", "docs/product/backlog*.json", "docs/product/attribution.json")


def build_bundle(agent_c_home: Path, dest: Path) -> int:
    if dest.exists():
        shutil.rmtree(dest)
    dest.mkdir(parents=True)
    for f in TOP_FILES:
        if (agent_c_home / f).exists():
            shutil.copy2(agent_c_home / f, dest / f)
    reg = json.loads((dest / "registry.json").read_text())
    n = 0
    for e in reg.get("entries", []):
        src = Path(e.get("path") or "")
        if not src.is_dir():
            continue
        target = dest / "projects" / e["slug"]
        for pat in PROJECT_GLOBS:
            for f in src.glob(pat):
                out = target / f.relative_to(src)
                out.parent.mkdir(parents=True, exist_ok=True)
                shutil.copy2(f, out)
        e["path"] = str(target); n += 1
    (dest / "registry.json").write_text(json.dumps(reg, indent=1))
    return n
