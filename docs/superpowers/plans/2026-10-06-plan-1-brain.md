# Snoop Plan 1 — The Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Revised 2026-10-09** after the adversarial review (`docs/product/critic-reports/2026-10-09-session-aec42f1e-orchestrator-contract.md`). Changes: no Bash in the brain (D38); reads confined to the knowledge folder by working-directory scoping, not a bare `Read` allow (D38); `snoop` gets its own primary group (D38); key passed only to the CLI and stripped from MCP children (D39); hardened setup (D40); every sandbox control re-run through the SDK as `snoop`, asserting denials and no errors (findings corrections); Serena pinned to a git commit.

**Goal:** A sandboxed, read-only "brain" that answers questions about the Agent-C repo, runnable on any roster member's Mac from a local clone with `./snoop setup` (once). It serves Desk Snoop (Plan 2) first and the Meet seat (Plan 4) later.

**Architecture:** Host-side Python (package `yosnoop/`; command `./snoop`) prepares knowledge in `/Users/Shared/snoop/knowledge` (clone, `git-facts.txt`, PR/CI status file, repo map, registry bundle on Brett's Mac) and launches the brain as macOS user `snoop` via a narrow sudoers rule. The brain is a long-lived process speaking JSON lines on stdin/stdout; it holds one Claude Agent SDK session per conversation, with **no Bash, no web, no writes**, and file reads confined to its working directory (the knowledge folder). The host's home is `700` and `snoop` is not in `staff`, so the OS also blocks it from the host's files. Every answer passes a secret-scanning gate.

**Tech Stack:** Python 3.12 (`uv`), `claude-agent-sdk` (0.2.163; bundled CLI 2.1.286), `mcp`, Serena (git-pinned), repomix (`npx repomix@<pinned>`), Agent-C `registry-mcp` (Node), macOS `sysadminctl`/`dscl`/`dseditgroup`/`visudo`, `gh`.

**Spec:** `docs/superpowers/specs/2026-10-05-yo-snoop-design.md` — D1, D12, D15, D16, D20–D23, D25, D33–D40; §3.2, §5.

## Global Constraints

- Phase 1a scope (D33): desk use first; no pre-loading, no pacing.
- No code names a person; hosts come from `config/team.json` (D31) and `~/.config/snoop/host.json`.
- Brain options are always: `cwd = knowledge dir`, `setting_sources=[]`, `strict_mcp_config=True`, `permission_mode="dontAsk"`, `max_turns=15`, settings `{"permissions": {"blockReadsOutsideWorkingDirectories": true}}`, `disallowed_tools` including bare `Bash`, `WebFetch`, `WebSearch`, `Write`, `Edit`, `NotebookEdit`, `Task`. **Never a bare `Read`/`Grep`/`Glob` allow rule** (it would allow reads everywhere); reads inside the working directory need no rule. Never `bypassPermissions`.
- The API key is passed only via `ClaudeAgentOptions(env=…)` to the CLI; never `os.environ` of the brain process; every MCP server command is prefixed with `/usr/bin/env -u ANTHROPIC_API_KEY` (D39).
- Host-side secrets live in `~/.config/snoop/secrets/` (mode 700). No secret is printed, committed, logged, or put on a command line. Tests build key-shaped strings by concatenation.
- Dry runs and scratch output go under `~/.cache/snoop/` (inside the `700` home), **never `/tmp`** — `/tmp` is readable by `snoop`.
- Paths: shared root `/Users/Shared/snoop` (`SHARED`); tests use `SNOOP_SHARED`.

## Review Focus

1. **Brain reads outside the knowledge folder** — expected: denied with a recorded permission denial, even for a file `snoop` can read at the OS level. Task 9, control C3.
2. **API key reaches an MCP child** — expected: the env-probe server reports it absent; the same probe without the wrapper reports it present (negative control). Task 9, control C5.

```python
# yosnoop/hostcfg.py
import json, os
from pathlib import Path
from yosnoop.roster import Member, Roster

def host_json_path() -> Path:
    return Path(os.environ.get("SNOOP_HOST_JSON", Path(os.environ["HOME"]) / ".config" / "snoop" / "host.json"))

def load_host(roster: Roster) -> Member:
    p = host_json_path()
    if not p.exists():
        raise SystemExit(f"no host config at {p}; run ./snoop setup")
    email = json.loads(p.read_text())["email"]
    m = roster.by_email(email)
    if m is None or not m.may_host:
        raise SystemExit(f"{email} is not a roster member who may host (config/team.json)")
    return m
```

```python
# yosnoop/setup_mac.py
"""One-time privileged setup. Generates one bash script, shows it, runs it under sudo once."""
import getpass, json, os, subprocess
from pathlib import Path
from yosnoop import paths
from yosnoop.roster import load


def setup_script(owner: str, owner_home: str, shared: str) -> str:
    return f"""#!/bin/bash
set -euo pipefail
SHARED="{shared}"
# 0. refuse a pre-planted shared path (symlink, or not a directory owned by the host)
if [ -L "$SHARED" ]; then echo "refusing: $SHARED is a symlink"; exit 1; fi
if [ -e "$SHARED" ] && {{ [ ! -d "$SHARED" ] || [ "$(stat -f %Su "$SHARED")" != "{owner}" ]; }}; then
  echo "refusing: $SHARED exists and is not a directory owned by {owner}"; exit 1
fi
# 1. snoop group and user: own primary group (not staff), hidden, no shell, random throwaway password
dseditgroup -o read snoop >/dev/null 2>&1 || dseditgroup -o create snoop
GID=$(dscl . -read /Groups/snoop PrimaryGroupID | awk '{{print $2}}')
if ! id snoop >/dev/null 2>&1; then
  sysadminctl -addUser snoop -fullName "Snoop Brain" -shell /usr/bin/false -password "$(openssl rand -base64 24)" -home /Users/snoop
  createhomedir -c -u snoop >/dev/null
fi
dscl . create /Users/snoop PrimaryGroupID "$GID"
dscl . create /Users/snoop IsHidden 1
chown -R snoop:snoop /Users/snoop
chmod 700 /Users/snoop
# 2. group that may read the shared knowledge
dseditgroup -o read snoopread >/dev/null 2>&1 || dseditgroup -o create snoopread
dseditgroup -o edit -a snoop -t user snoopread
# 3. shared dirs: created fresh, owner writes, snoop reads; no recursion over existing content
install -d -o {owner} -g snoopread -m 750 "$SHARED" "$SHARED/knowledge" "$SHARED/runtime" "$SHARED/bin"
# 4. the wall: owner's home closed to every other local user
chmod 700 {owner_home}
# 5. owner may start the brain as snoop, nothing else; HOME is snoop's own
TMP=$(mktemp)
printf '%s\\n' 'Defaults>snoop always_set_home' '{owner} ALL=(snoop) NOPASSWD: {shared}/bin/brain' > "$TMP"
visudo -cf "$TMP"
install -m 0440 -o root -g wheel "$TMP" /etc/sudoers.d/snoop
rm -f "$TMP"
echo "snoop setup: done"
"""


def run_setup(argv: list[str]) -> int:
    from yosnoop.cli import ROSTER
    roster = load(ROSTER)
    email = input("Your saasless.ai email (must be in config/team.json): ").strip().lower()
    m = roster.by_email(email)
    if m is None or not m.may_host:
        print(f"{email} is not a roster member who may host"); return 1
    host_json = Path(os.environ["HOME"]) / ".config" / "snoop" / "host.json"
    host_json.parent.mkdir(parents=True, exist_ok=True)
    host_json.write_text(json.dumps({"email": m.email}))
    script = setup_script(getpass.getuser(), os.environ["HOME"], str(paths.shared()))
    print(script)
    if input("Run this once with sudo? Type 'yes': ").strip() != "yes":
        print("not run"); return 1
    f = paths.scratch_dir() / "setup.sh"
    f.write_text(script); f.chmod(0o600)
    rc = subprocess.run(["sudo", "bash", str(f)]).returncode
    f.unlink()
    if rc != 0:
        print(f"setup failed rc={rc}"); return rc
    from yosnoop.doctor import run_doctor
    return run_doctor([])
```

```python
# yosnoop/runtime_sync.py
import shutil, subprocess
from pathlib import Path

AGENT_C = Path.home() / "Code" / "Saasless" / "Agent-C"


def brain_wrapper(runtime: Path, knowledge: Path) -> str:
    return (f"#!/bin/sh\nexport HOME=/Users/snoop\ncd {knowledge}\n"
            f"exec {runtime}/.venv/bin/python -m yosnoop.brain_main \"$@\"\n")


def sync_runtime(repo_root: Path, runtime: Path, runner=subprocess.run) -> None:
    runtime.mkdir(parents=True, exist_ok=True)
    py = runtime / "python"
    runner(["uv", "python", "install", "3.12", "--install-dir", str(py)], check=True)
    runner(["uv", "venv", "--python", str(py), "--allow-existing", str(runtime / ".venv")], check=True)
    runner(["uv", "pip", "install", "--python", str(runtime / ".venv" / "bin" / "python"), str(repo_root)], check=True)
    reg = AGENT_C / "registry-mcp"
    if (reg / "out").exists():
        dest = runtime / "registry-mcp"
        if dest.exists():
            shutil.rmtree(dest)
        shutil.copytree(reg / "out", dest / "out")
        shutil.copytree(reg / "node_modules", dest / "node_modules", symlinks=True)
        shutil.copy2(reg / "package.json", dest / "package.json")
```

```python
# yosnoop/gate.py
import re
from dataclasses import dataclass

BLOCKED = "Snoop here, can't share that one."
PATTERNS = {
    "anthropic-key": re.compile(r"sk-ant-[A-Za-z0-9_-]{20,}"),
    "github-token": re.compile(r"\b(ghp|gho|ghu|ghs|ghr)_[A-Za-z0-9]{30,}\b"),
    "github-pat": re.compile(r"github_pat_[A-Za-z0-9_]{40,}"),
    "aws-access-key": re.compile(r"\bAKIA[0-9A-Z]{16}\b"),
    "private-key": re.compile(r"-----BEGIN [A-Z ]*PRIVATE KEY-----"),
    "google-service-account": re.compile(r'"type"\s*:\s*"service_account"'),
    "generic-bearer": re.compile(r"\bBearer\s+[A-Za-z0-9._-]{30,}"),
}


@dataclass(frozen=True)
class GateResult:
    allowed: bool
    text: str
    reason: str | None


def scan(text: str) -> list[str]:
    return [name for name, rx in PATTERNS.items() if rx.search(text)]


def gate(answer: str) -> GateResult:
    try:
        hits = scan(answer)
    except Exception:
        return GateResult(False, BLOCKED, "scanner-error")
    if hits:
        return GateResult(False, BLOCKED, "secret:" + ",".join(hits))
    return GateResult(True, answer, None)
```

```python
# yosnoop/refresher.py
import json, subprocess, time
from dataclasses import dataclass, field
from pathlib import Path
from yosnoop.gate import scan

REPOMIX = "repomix@1"  # Step 4 pins the exact version
INCLUDE = "docs/**/*.md,ARCHITECTURE.md,CLAUDE.md,scripts/**/*.js,registry-mcp/src/**/*.ts,agents/**/SKILL.md"


def run_gh(args: list[str], cwd: Path | None = None) -> str:
    return subprocess.run(["gh", *args], capture_output=True, text=True, check=True, cwd=cwd).stdout


def run_repomix(clone: Path, out: Path) -> None:
    subprocess.run(["npx", "-y", REPOMIX, "--compress", "--style", "xml", "--include", INCLUDE,
                    "--output", str(out), str(clone)], check=True, capture_output=True)


def _git(clone: Path, *args: str) -> str:
    return subprocess.run(["git", "-C", str(clone), *args], capture_output=True, text=True, check=True).stdout


def git_facts(clone: Path) -> str:
    branches = _git(clone, "for-each-ref", "--sort=-committerdate", "refs/remotes/origin",
                    "--format=%(refname:short)\t%(committerdate:iso)\t%(subject)")
    log = _git(clone, "log", "--all", "-n", "300", "--date=iso", "--name-only",
               "--format=--- %h %ad %an%n%s")
    return "# Branches (newest first)\n" + branches + "\n# Recent commits, all branches\n" + log


@dataclass
class RefreshReport:
    ok: bool
    clone_age_s: float
    map_blocked: bool = False
    errors: list[str] = field(default_factory=list)


class Refresher:
    def __init__(self, origin: str, knowledge: Path, gh=None, repomix=run_repomix, now=time.time):
        self.origin, self.k, self.repomix, self.now = origin, Path(knowledge), repomix, now
        self.gh = gh or (lambda args: run_gh(args, cwd=self.k / "agent-c"))

    def refresh(self) -> RefreshReport:
        self.k.mkdir(parents=True, exist_ok=True)
        clone, errors = self.k / "agent-c", []
        try:
            if (clone / ".git").exists():
                subprocess.run(["git", "-C", str(clone), "fetch", "-q", "--prune", "origin",
                                "+refs/heads/*:refs/remotes/origin/*"], check=True)
                subprocess.run(["git", "-C", str(clone), "reset", "-q", "--hard", "origin/main"], check=True)
            else:
                subprocess.run(["git", "clone", "-q", self.origin, str(clone)], check=True)
            (self.k / "git-facts.txt").write_text(git_facts(clone))
            (self.k / "refreshed-at").write_text(str(self.now()))
        except subprocess.CalledProcessError as e:
            errors.append(f"git: {e}")
        try:
            status = {"pull_requests": json.loads(self.gh(["pr", "list", "--state", "all", "--limit", "30", "--json",
                                                           "number,title,state,author,mergedAt,reviewDecision,headRefName"])),
                      "runs": json.loads(self.gh(["run", "list", "--limit", "30", "--json",
                                                  "headBranch,conclusion,status,createdAt,workflowName"]))}
            (self.k / "pr-ci-status.json").write_text(json.dumps(status, indent=1))
        except Exception as e:
            errors.append(f"gh: {type(e).__name__}")
        blocked, map_path = False, self.k / "repo-map.xml"
        try:
            self.repomix(clone, map_path)
            if scan(map_path.read_text()):
                map_path.unlink(); blocked = True
        except Exception as e:
            errors.append(f"repomix: {type(e).__name__}")
        f = self.k / "refreshed-at"
        age = self.now() - float(f.read_text()) if f.exists() else float("inf")
        return RefreshReport(ok=not errors, clone_age_s=age, map_blocked=blocked, errors=errors)
```

```python
import json
from pathlib import Path
from claude_agent_sdk import ClaudeAgentOptions
from yosnoop.serena_cfg import KEEP

KEY_STRIP = ["/usr/bin/env", "-u", "ANTHROPIC_API_KEY"]
DISALLOWED = ["Bash", "WebFetch", "WebSearch", "Write", "Edit", "NotebookEdit", "Task"]
REGISTRY_READ_TOOLS = ["registry_list", "registry_get", "stage_get", "stage_diagnose", "backlog_list",
                       "backlog_get", "history_events", "history_metrics", "server_info"]
SETTINGS = json.dumps({"permissions": {"blockReadsOutsideWorkingDirectories": True}})
SYSTEM = """You are Snoop, answering a Saasless team's questions about the Agent-C repo.
Answer only from files in your working directory and your tools. If you cannot find it, say "not in my notes".
git-facts.txt has branches and recent commits; pr-ci-status.json has pull requests and CI; repo-map.xml summarizes the code.
Lead with the answer. Plain sentences, no markdown; say identifiers exactly. Never claim CI passed unless a run says so.
Return the answer as short self-contained points, most important first. Never say the words "peanut butter"."""


def _server(cmd: list[str], env: dict | None = None) -> dict:
    s = {"type": "stdio", "command": KEY_STRIP[0], "args": [*KEY_STRIP[1:], *cmd]}
    if env:
        s["env"] = env
    return s


def build_options(knowledge: Path, registry_cmd, serena_cmd, model: str, persona: str = "", api_key: str | None = None):
    allowed, servers = [], {}
    if registry_cmd:
        servers["registry"] = _server(registry_cmd, {"AGENT_C_HOME": str(knowledge / "agent-c-home"),
                                                     "CLAUDE_PROJECTS_DIR": str(knowledge / "empty-projects")})
        allowed += [f"mcp__registry__{t}" for t in REGISTRY_READ_TOOLS]
    if serena_cmd:
        servers["serena"] = _server(serena_cmd)
        allowed += [f"mcp__serena__{t}" for t in sorted(KEEP)]
    return ClaudeAgentOptions(
        allowed_tools=allowed, disallowed_tools=DISALLOWED, mcp_servers=servers, strict_mcp_config=True,
```

```python
# yosnoop/brain_main.py
"""The brain. Runs as `snoop` (production) or the host (--dev). JSON lines on stdin/stdout."""
import asyncio, json, sys, time
from pathlib import Path

def out(obj): sys.stdout.write(json.dumps(obj) + "\n"); sys.stdout.flush()

def selftest(paths):
    readable, unreadable = [], []
    for p in paths:
        try:
            open(p, "rb").read(1); readable.append(p)
        except OSError:
            unreadable.append(p)
    out({"readable": readable, "unreadable": unreadable})

def clone_age(k: Path) -> float:
    f = k / "refreshed-at"
    return time.time() - float(f.read_text()) if f.exists() else float("inf")

async def serve():
    from claude_agent_sdk import ClaudeSDKClient, ResultMessage
    from yosnoop.brain_opts import build_options
    from yosnoop import paths
    k = paths.knowledge_dir()
    cfg = json.loads((k / "brain-config.json").read_text()) if (k / "brain-config.json").exists() else {}
    credential, key, client = None, None, None
    loop = asyncio.get_running_loop()
    while True:
        line = await loop.run_in_executor(None, sys.stdin.readline)
        if not line:
            break
        msg = json.loads(line)
        t = msg.get("type")
        if t == "key":
            credential, key = "key", msg["value"]; continue
        if t == "dev":
            credential = "dev"; continue
        if t == "end_meeting":
            if client: await client.__aexit__(None, None, None); client = None
            continue
        if t != "ask":
            continue
        if credential is None:
            out({"type": "error", "id": msg["id"], "reason": "no-credential"}); continue
        try:
            if client is None:
                client = ClaudeSDKClient(options=build_options(k, cfg.get("registry_cmd"), cfg.get("serena_cmd"),
                                                               cfg.get("model", "claude-sonnet-5-5"),
                                                               cfg.get("persona", ""), api_key=key))
                await client.__aenter__()
            await client.query(f"[{msg['asker']} asks, room={msg['room']}] {msg['question']}")
            text = ""
            async def collect():
                nonlocal text
                async for m in client.receive_response():
                    if isinstance(m, ResultMessage):
                        text = m.result or ""
            await asyncio.wait_for(collect(), timeout=90)
            out({"type": "answer", "id": msg["id"], "text": text, "clone_age_s": clone_age(k)})
        except asyncio.TimeoutError:
            out({"type": "error", "id": msg["id"], "reason": "timeout"})
        except Exception as e:
            out({"type": "error", "id": msg["id"], "reason": type(e).__name__})

def main():
    if len(sys.argv) > 1 and sys.argv[1] == "--selftest":
        selftest(sys.argv[2:]); return
    asyncio.run(serve())

if __name__ == "__main__":
    main()
```

```python
import json, shutil
from pathlib import Path

TOP_FILES = ("registry.json", "events.ndjson", "runs.json", "recent.json")
PROJECT_GLOBS = ("docs/**/state.json", "docs/product/backlog*.json", "docs/product/attribution.json")


def build_bundle(agent_c_home: Path, dest: Path) -> int:
    if dest.exists():
        shutil.rmtree(dest)
    dest.mkdir(parents=True)
    for f in TOP_FILES:
        if (agent_c_home / f).exists():
            shutil.copy2(agent_c_home / f, dest / f)
    reg = json.loads((dest / "registry.json").read_text())
    n = 0
    for e in reg.get("entries", []):
        src = Path(e.get("path") or "")
        if not src.is_dir():
            continue
        target = dest / "projects" / e["slug"] if e.get("slug") else dest / "projects" / e["id"]
        for pat in PROJECT_GLOBS:
            for f in src.glob(pat):
                o = target / f.relative_to(src)
                o.parent.mkdir(parents=True, exist_ok=True)
                shutil.copy2(f, o)
        e["path"] = str(target); n += 1
    (dest / "registry.json").write_text(json.dumps(reg, indent=1))
    return n
```
